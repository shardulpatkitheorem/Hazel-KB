# Decision Registry

This is a derived index. The originating iteration remains the source of truth.

## Entry format

```markdown
### DEC-001 — Short decision title

- Status: active | superseded
- Effective date: YYYY-MM-DD
- Decision: Exact approved statement
- Owners: Named authority or `unknown`
- Evidence: `iterations/<iteration-id>/meeting-delta.json#<item-id>`
- Implemented by: PR URL or `not-applicable`
- Superseded by: Decision ID or `not-applicable`
```

Do not add proposals, assumptions, or unresolved discussion.
